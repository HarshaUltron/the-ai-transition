A note before you begin

AI is no longer just a tool that helps us write code.

It can write the code.

It can test the code.

It can explain the code.

It can suggest architectures, debug failures, deploy systems, and increasingly perform entire chains of technical work.

So a question is becoming harder to ignore:

If machines can do the work, what happens to the people who used to do it?

This is not a prediction that AI will replace everyone.

It is an attempt to think seriously about what happens if AI keeps becoming more capable — to software engineers, to careers, to companies, and to economies built around human knowledge work.
